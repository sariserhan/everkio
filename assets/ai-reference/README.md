# Synthetic animal references

Original cat/dog reference PNGs created with the built-in imagegen tool for Everkio's generic AI-to-3D evaluation. These are inputs, not product assets, actual-pet reconstructions, AR screenshots or realism acceptance evidence. Prompts, transparent-background request and image hashes are recorded in `manifest.json`; underlying image-model version is not exposed by the tool.

See [the local generation workflow](../../docs/ai-animal-generation.md) for model/source provenance, commands and actual mesh results. Generated evaluation meshes and failed attempts remain private under ignored `artifacts/ai-animals-001/`.
